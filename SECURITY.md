# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in ChronosML, please report it responsibly by opening a security advisory on the [GitHub repository](https://github.com/kardashevproject/chronosml/security/advisories) or emailing `admin@kardashevproject.org`.
